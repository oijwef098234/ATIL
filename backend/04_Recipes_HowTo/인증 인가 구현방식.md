## 기본 로그인

### 개요

- 로그인 시 **Access Token + Refresh Token**을 모두 발급
- 사용 중 Access Token이 만료되기 전에 **reissue 요청으로 갱신**
- 브라우저를 닫지 않는 동안 로그인 상태 유지

### 흐름

1. 로그인
    - Access Token 발급 - json
    - Refresh Token 발급 - json
2. 서비스 사용 중
    - Access Token 만료 직전 → reissue 요청
    - 새로운 Access Token 발급 - json
3. 브라우저 종료
    - Access Token 메모리 소멸
    - refreshToken 메모리 소멸

### 특징

- 브라우저 재시작 시 자동로그인은 보장되지 않음
- 구현이 쉬움

# 기본 로그인 + 자동로그인

## remember-me 체크되어있다면

### 개요

- Refresh Token을 **만료시간이 있는 영속 쿠키**로 발급
- 브라우저를 닫았다 다시 열어도 로그인 유지

### 흐름

1. 로그인
    - Access Token 발급 - cookie(세션 쿠키), or json
    - Refresh Token 발급 - cookie(영속 쿠기)
2. 브라우저 종료 후 재실행
    - Access Token 없음
    - 브라우저에 남아있는 Refresh Token 쿠키 자동 전송
3. 앱 시작 시
    - 프론트에서 reissue 요청
    - 새로운 Access Token 발급
    - 로그인 상태 복구

### 특징

- 브라우저 종료 후에도 로그인 유지
- Refresh Token 탈취 리스크 존재

---

## remember-me 체크되어있지 않다면

### 개요

- 로그인 시 **Access Token + Refresh Token**을 모두 발급
- reissue를 사용해서 계속 토큰을 갱신하여도 됨

### 흐름

1. 로그인
    - Access Token 발급 - cookie(세션 쿠키)
    - Refresh Token 발급 - cookie(세션 쿠기)
2. 브라우저 종료 후 재실행
    - Access Token 없음
    - 자동로그인 안됨
3. 앱 시작 시
    - 자동로그인 안됨

### 특징

- 브라우저 재시작 시 자동로그인은 보장되지 않음
- 구현이 쉬움
