## Authentication 객체란?

> spring 에서 인증 정보를 나타내는 객체입니다.

- Authentication 객체는 인증 과정을 통해 생성되며, 사용자의 자격 증명(예: 사용자 이름과 비밀번호)을 기반으로 신원을 확인합니다

## 인증 프로세스의 과정

1. _**사용자가 자격 증명(사용자 이름과 비밀번호)을 제공합니다.**_
2. _**제공된 자격 증명을 기반으로 사용자의 신원을 확인하기 위해 인증 과정이 시작됩니다.**_
3. _**인증 과정은 UserDetailsService를 사용하여 사용자의 신원을 확인하고, 사용자 정보와 권한 정보를 가져옵니다.**_
4. _**인증이 성공적으로 완료되면, 인증 객체인 Authentication 객체가 생성됩니다. 이 객체는 사용자의 신원 정보와 부여된 권한 정보를 포함합니다.**_
5. _**생성된 Authentication 객체는 인증된 사용자를 나타내며, 이후의 보호된 리소스에 접근할 때 사용됩니다.**_
