## static이란?

> 객체를 생성하지 않고 클래스, 메서드, 필드를 사용할 수 있게 한다.

우선 왜 객체를 생성하지 않고 클래스나 메서드를 사용하는 상황이 생길까?

### 객체를 생성하는 이유

> 객체는 상태를 가지기 위해 존재한다.

```java
User user = new User("홍길동", 17);
```

- 이런 코드가 있으면 user라는 상태를 담고 있는 객체가 필요함

하지만

- 두 숫자 더해줘
- 문자열 길이 알려줘
- 파일 경로 합쳐줘
- 상수값 반환해줘

이런 식으로 굳이 클래스에 대한 객체를 만들지 않아도 모든 객체들이 똑같은 행위를 하면 굳이 static을 사용할 이유가 없어진다.

---

### static이 필드에 붙는 경우

> c언어로 비유하면 모든 클래스 어디서든 같은 값을 가지고 공유하는경우, 전역변수같은 느낌이다.

- static이 있는 필드 : 객체마다 다른 값을 가진다.
- static이 없는 필드 : 모든 객체가 같은 값을 가진다.
