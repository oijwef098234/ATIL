## 접근제어자란?

> 접근제어자란 변수, 메소드, 클래스 선언시 사용되며 해당 변수, 메소드, 클래스의 접근을 제한하는 역할을 한다

### public 접근 제어자

> 제한없이 접근이 가능한 접근제어자

- 일반적으로 클래스에 많이 사용한다.

### private 접근제어자

> 동일한 클래스 내에서만 접근할 수 있도록 하는 접근제어자

- 보통 필드를 선언할 때 많이 사용한다.

### protected 접근 제어자

> private는 상속받은 자식도 접근을 못하는 반면 이 친구는 상속을 받은 자식은 사용을 할 수 있다.

- 같은 패키지 내에 있으면 사용이 가능하다.
