## **STOMP란?**

> 메시징 시스템 간에 데이터를 교환하기 위한 간단하면서도 유연한 텍스트 기반 프로토콜

- WebSocket 위에서 동작하는 메시지 전송 규칙

## 왜 사용하냐?

초반 웹소켓은

- 연결 유지됨
- 실시간 가능

> 너무 자유로워서 아무것도 정해지지 않음, 따라서 등장하게 되었다.

- 따라서 **STOMP**를 사용하면 웹소켓을 사람이 쓸 수 있게 만들 수 있다.

## **STOMP 핵심 개념**

## 1. Destination (주소 개념)

- 통신채널 이름같은 느낌

```
/pub/chat.send
/sub/chat/1
```

---

## 2. publish (보내기)

- 말그대로 메시지 보내기

```
/pub/chat.send
```

---

## 3. subscribe (구독)

- 실시간 통신 상태

```
/sub/chat/1
```

---

## 4. broker (중간 분배자)

- 메시지 받음
- 구독자에게 뿌림
