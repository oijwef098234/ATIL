## Preflight Request란?

> 프리플라이트 요청은 **브라우저가 실제 요청 전에** 서버에 보내는 **사전 검사 요청**

- 이를 통해 서버가 해당 출처를 허용하는지 확인할 수 있음
- 프리플라이트 요청은 **OPTIONS** 메서드를 사용해 서버로 보내진다.

### 주로 다음과 같은 상황에서 많이 발생됨

- **PUT**, **DELETE** 등 **비표준 HTTP 메서드**를 사용하는 경우.
- **커스텀 헤더**를 포함하는 경우.
- **Content-Type**이 `application/json` 또는 `multipart/form-data`와 같은 경우.
